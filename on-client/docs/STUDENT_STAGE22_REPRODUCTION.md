# 우사기강 22단계 재현·버전 기록

이 문서는 22단계 「최종 커밋의 새 환경 재현과 릴리스 기록」의 **학생 실행 기록 양식과 현재 확인 범위**를 담습니다. 기록을 채우기 전에는 재현 성공으로 간주하지 않습니다. 문서의 절차를 읽거나 코드 원문을 검토한 것은 새 환경에서 실행한 증거가 아닙니다.

## 1. 무엇을 재현하는가

제출 예정인 **동일한 40자리 커밋 하나**를 원래 작업 폴더와 분리된 새 폴더에서 가져와 확인합니다. 원래 프로젝트 폴더와 Git 기록은 보존합니다. 기존 폴더의 인증·개인 설정 파일을 새 폴더로 무작정 복사하지 않습니다.

새 환경에서 수행할 순서는 다음과 같습니다.

1. 원래 프로젝트의 저장소 주소, 브랜치, 제출할 40자리 커밋을 실제 값으로 기록합니다. 현재 이 문서 작성 시에는 이 값들이 제공되지 않아 비워 둡니다.
2. 원래 폴더와 별개인 새 빈 폴더를 준비합니다. 실제 저장소와 커밋을 확인한 후 그 동일 커밋의 원문을 가져옵니다. 공개 저장소라면 Git을 사용할 수 있고, 비공개 저장소라면 과제 화면의 해당 단계 안내와 원문 전달 도구를 따릅니다. 저장소 주소나 커밋을 추측하거나 이 문서에 도구 명령을 만들어 넣지 않습니다.
3. [21단계 학생 실행 안내](STUDENT_STAGE21_REFERENCE.md)에 따라 런타임 버전 확인, 실행, 브라우저 확인, 종료, 재실행을 수행합니다. 설치·실행 과정에서 나온 값과 실제 관찰을 아래 기록표에 남깁니다.
4. 실행을 확인한 뒤에도 AI·SDP 연결이나 보안 조치의 실제 효과는 별도 확인 항목으로 남깁니다. `demo` 실행은 예제 자료 시연이며 실제 계정·업무 시스템 연결의 증거가 아닙니다.

명령을 실행할 작업 위치는 **새 재현 폴더 안의 `on-client` 앱 폴더**입니다. `package.json`에 선언된 명령은 `npm start`, `npm run demo`, `npm run check`입니다. [21단계 학생 실행 안내](STUDENT_STAGE21_REFERENCE.md)는 기본 주소 `http://127.0.0.1:5189`를 안내합니다. 실제 시작 포트와 메시지는 새 환경에서 직접 확인해 기록해야 합니다. `npm run check`는 `student/extension.mjs`의 Node.js 구문 확인 명령이며, 앱 동작이나 시스템 연결 검증은 아닙니다.

## 4. 13~21단계 누적 확인표

아래는 **이번 문서 작성에서 확인 가능한 범위**를 정리한 표입니다. `student/extension.mjs` 읽기 결과는 도구 출력이 일부 생략되어 함수 본문 전체의 대조를 완료하지 못했습니다. 따라서 단계별 함수명은 과제 안내를 기준으로 한 범위이며, 현재 제출 커밋의 구현 판정이 아닙니다. 실제 화면 결과, 제출 커밋, 서버 AI 판정은 증거가 제공되지 않아 미확인입니다. 실제로 확인한 뒤 각 칸을 같은 커밋의 근거로 갱신합니다.

| 단계·기능 | 이번 원문 검토 결과 | 모의 입력 결과 | 실제 화면·시스템 결과 | 확인 시각·근거 | 미확인 원인 |

## 5. 데이터 보존·백업·복원 계획과 한계

- **코드와 문서:** 제출 커밋을 기준 원문으로 삼습니다. 새 환경 재현은 별도 폴더에서 수행하고 원래 프로젝트와 Git 기록은 그대로 둡니다. 재현 중 수정이 필요하면 원래 제출 커밋을 덮어쓰지 않고 수정본은 별도 변경·새 커밋으로 구분합니다.
- **비밀 설정·자격 자료:** 키·토큰·비밀번호와 개인 인증 설정을 저장소나 기록표에 넣지 않습니다. 새 환경으로 무작정 복사하지 않으며, 필요한 경우 담당자가 승인한 절차로 다시 준비합니다. 이 문서에는 자격 자료의 값이나 개인 경로를 기록하지 않습니다.
- **업무 기록·계정 데이터:** 접속 기록, 기기·세션 정보, XDR 경보 및 SDP 자료는 연동 시스템의 제공 범위에 따릅니다. 이 문서는 해당 자료를 로컬 프로젝트가 백업한다고 보장하지 않습니다. 원천 시스템 소유자의 보존·복구 절차를 확인해야 합니다.
- **조치 기록 저장소:** 제공 코드에는 조치 저장소 모듈(`src/actions/store.mjs`)이 있습니다. 이 문서 검토만으로 실제 환경의 저장 경로, 백업 절차, 복원 결과를 확인하지 못했습니다. 실행 중인 데이터베이스를 임의로 복사하거나 복원하지 말고, 담당자가 확인한 저장 경로와 일관성 있는 백업·복구 절차를 사용합니다. 이 절차가 마련되고 복원 시험을 하기 전까지 백업·복원은 미검증입니다.
- **복원 확인:** 복원 책임자, 승인된 백업 원본·시점, 복원 절차, 복원 후 확인 항목과 결과를 별도로 기록합니다. 이 프로젝트 문서만으로 데이터 복원을 완료했다고 표시하지 않습니다.

## 6. 지원 범위·미해결 사항·릴리스 표현

- `package.json`이 선언하는 Node.js 기준은 `24.19.0`입니다. 새 환경의 실제 런타임 버전이나 별도 운영 환경 지원 여부는 확인되지 않았습니다.
- 기본 실행·예제 실행·문법 확인은 서로 다른 절차입니다. 예제 자료의 표시를 실제 시스템 연결 성공으로 해석하지 않습니다.
- 19단계의 실제 보안 조치 집행 연결은 아직 준비되지 않았으며, 학생 개인에게 운영자 자격 발급이나 집행기 구축을 요구하지 않습니다. 실제 학생 계정의 조치 처리는 미확인입니다.
- 코드 원문 검토는 실행 성공 증명이 아닙니다. 22단계 통과는 원문 검토 기준의 수료이지 실제 운영 인증이나 `v1.0` 자동 인증이 아닙니다.
- 실제 저장소 주소·브랜치·40자리 최종 커밋, 새 환경 버전, 재현 절차 결과, 브라우저 관찰, 단계별 근거, 백업·복원 시험 결과가 입력되지 않았습니다. 따라서 현재 릴리스 상태는 **재현 기록 대기·검증 중**이며, `v1.0` 또는 새 환경 재현 완료라고 주장하지 않습니다.
